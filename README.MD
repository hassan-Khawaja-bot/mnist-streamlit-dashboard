# MNIST Digit Classification – Streamlit Dashboard

A complete machine learning project that demonstrates **handwritten digit classification using the MNIST dataset**, including model development in a Jupyter Notebook and an **interactive Streamlit dashboard** for real-time predictions.

---

## 📌 Project Overview

This project consists of two main components:

- **Model Development (Jupyter Notebook)**  
  Building, training, and evaluating an MNIST digit classification model.

- **Web Dashboard (Streamlit App)**  
  An interactive Streamlit-based dashboard that allows users to run predictions using the trained model.

This project is designed to showcase **machine learning fundamentals, Python skills, and basic MLOps practices** in a clean and professional manner.

---
